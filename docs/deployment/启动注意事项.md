## 三、启动过程中发现的问题及修复

### 问题 1：`.venv` 指向已不存在的 Python 路径
- **现象**：`start.bat` 原本配置的 `.venv` 由 Python 3.13.8 创建，但本机实际安装的是 Python 3.14.8，导致 `pydantic_core._pydantic_core` 二进制不兼容。
- **修复**：删除旧 `.venv`，用 `D:/Python/python.exe` 重新创建虚拟环境并安装依赖。
- **命令**：
  ```bash
  rm -rf .venv
  D:/Python/python.exe -m venv .venv
  .venv/Scripts/python.exe -m pip install -r requirements.txt
  ```

### 问题 2：`requirements.txt` 缺少 `minio` 包
- **现象**：启动时 `from minio import Minio` 报 `ModuleNotFoundError`。
- **修复**：手动安装 `minio`：
  ```bash
  .venv/Scripts/python.exe -m pip install minio
  ```
  > 后续应在 `requirements.txt` 中补充 `minio==7.2.20`。

### 问题 3：`src/core/config.py` 内容损坏
- **现象**：文件的 `DATABASE_URL` property 和末尾部分被乱码/错误内容覆盖，无法正常加载配置。
- **修复**：重写 `config.py`，确保 `DATABASE_URL` 正确返回 SQLite 连接串，并保留完整的 `MINIO_*` 等配置项。

## 五、停止服务

直接关闭启动后打开的两个命令行窗口即可。或在终端执行：
```bash
# 停止后端（Windows PowerShell）
Get-Process python | Stop-Process -Force

# 停止前端（Windows PowerShell）
Get-Process node | Stop-Process -Force
```

## 六、切换到 MySQL + 真实 Redis + 真实 MinIO（可选）

如需使用 Docker Compose 基础设施：

```bash
# 1. 启动 Docker 服务
docker compose -f docker/docker-compose.yaml up -d

# 2. 修改 .env，取消注释 MySQL / Redis 配置
# DB_HOST=localhost
# DB_PORT=3306
# DB_USER=root
# DB_PASSWORD=123456
# DB_NAME=chenguang

# REDIS_HOST=localhost
# REDIS_PORT=6379
# REDIS_PASSWORD=123456
# REDIS_DB=0

# MINIO_ENDPOINT=localhost:9000
# MINIO_ACCESS_KEY=minioadmin
# MINIO_SECRET_KEY=minioadmin

# 3. 重新初始化数据库
.venv/Scripts/python.exe bootstrap_db.py
```

> 注意：`docker-compose.yaml` 中 MinIO 的 root password 为 `minioadmin123`，与 `.env` 中 `MINIO_SECRET_KEY=minioadmin` 不一致，需同步修改其一。
