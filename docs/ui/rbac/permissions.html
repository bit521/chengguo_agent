编辑权限

权限码不可修改，避免已授权的角色失效。

如需新的权限码，请新建权限并重新分配。

新建权限

权限码由模块与动作拼成，例如 knowledge:upload。

生成的权限码：module:action
请检查名称与动作；权限码需为「模块:动作」且不能重复。
推荐动作：list、create、update、delete、publish、execute、assign、upload、retrieval、test。
