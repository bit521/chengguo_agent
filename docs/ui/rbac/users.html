分配角色

为用户选择角色，保存后即生效。

有效权限是所选角色的并集。角色变更在下一次请求生效，无需重新登录；界面在刷新后更新。 没有角色的账号只保留工作台与个人设置入口。
所需权限 role:assign

新建用户

创建后账号默认没有角色，需要再分配角色才能访问业务模块。

密码规则沿用现有后端，不在本次改造范围。
请填写姓名、账号与初始密码。

删除用户

删除后该账号立即失效，关联的用户角色关系一并移除。

即将删除「—」。该操作不可恢复。

所需权限 user:delete。原型不会写入数据。
