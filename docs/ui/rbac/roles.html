编辑角色

角色名称与描述可修改；角色码用于授权判定。

小写字母开头，可含小写字母、数字与下划线。
角色码格式不正确，或已存在同名角色码。

新建角色

创建后默认没有任何权限，请在权限矩阵中逐项勾选。

请填写名称与角色码；角色码需以小写字母开头且不可重复。
不新增内置角色。需要只读角色时，在此创建并只勾选 list 类权限。

删除角色

删除后，持有该角色的用户将失去这些权限。

即将删除「—」。关联的用户角色关系会一并移除，权限在下一次请求生效。
