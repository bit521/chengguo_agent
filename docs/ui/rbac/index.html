RBAC 授权界面原型 · V2.0
2026-10-27 · 基线 PROJECT_SPEC_V2（2026-10-25）

每一次访问，
先判定，再呈现。

这份原型把权限从「被存储」接到「被判定」。登录后加载角色与权限码，菜单、路由与操作按钮按权限呈现； 越权直达展示 403，而不是先渲染页面再报错。原型覆盖 PROJECT_SPEC_V2 的全部前端授权要求。

这是一套为企业权限管理设计的工作界面，不是通用 SaaS 卡片后台。墨绿承担导航与允许，朱砂只用于拒绝与删除， 黄铜标记当前身份与页面强调；状态使用方正的印章式标签，权限码使用等宽字体，让「规则」本身成为视觉结构。
