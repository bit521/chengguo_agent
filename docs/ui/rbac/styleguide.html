权限码与判定

权限码格式为 模块:动作，全局唯一。比较为精确匹配，不做前缀匹配；未匹配到任何权限时默认拒绝。

通配规则

写法含义使用范围
agent:list精确匹配一个动作自定义角色
agent:*该模块全部动作模块负责人
*全部权限仅 admin 角色

判定顺序

  1. 缺少 token、非法或过期 → 401
  2. 用户不存在或已禁用 → 401
  3. is_superuser=true → 放行
  4. 命中 *、模块:* 或精确权限码 → 放行
  5. 否则 → 403，业务逻辑不执行
// 前端只决定“看不看得见”，后端决定“做不做得成”
<button data-perm="agent:create">新建 Agent</button>
// has('agent:create') → 隐藏；接口仍可能返回 403

间距、形状与动效

间距取 4 的倍数，常用 8 / 12 / 16 / 20 / 24 / 32。面板 1px 边框、3px 圆角、无阴影；仅对话框使用大阴影。

动效

  • 页面标题下的黄铜规则线在加载时从左展开 550ms，全页仅此一处自动动效。
  • 悬停与焦点过渡 150ms；对话框进入 180ms。
  • prefers-reduced-motion 下关闭全部动画与过渡。

可访问性

已落实

  • 正文与次要文字对比度 ≥ 4.5:1；朱砂仅用于 12px 以上的强调文字。
  • 所有可交互元素有可见的 2px 黄铜焦点环（偏移 2px）。
  • 状态不只靠颜色：印章带圆点与文字，权限码带等宽字符。
  • 表格使用语义化 thead/th，表单控件均有 label；对话框有 role=dialog 与 aria-modal。
  • 图标按钮均带 aria-label。

刻意避免

  • 通用蓝色 SaaS 后台与同质化圆角卡片堆叠。
  • 渐变装饰、胶囊标签、全大写标签与多余的分隔圆点。
  • 无意义的 01 / 02 编号（仅页面清单与流程使用）。
  • 每个区块的淡入上浮与卡片逐个悬停放大。
